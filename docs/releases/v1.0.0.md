# LazaScrub v1.0.0

First public release of LazaScrub, a portable Windows utility that lists the metadata hidden in photos, PDFs and Office documents, removes it, and verifies the cleaned copy.

## Included

- Inspect JPEG, PNG, GIF and WebP pictures, PDFs, and Word, Excel and PowerPoint files, with every field rated high, medium or low risk.
- Write a cleaned copy without changing the original, then scan the copy again and confirm that its picture data or document content matches.
- Report and remove earlier versions left inside a PDF by incremental saves.
- Find metadata in pictures embedded in PDFs and Office documents.
- Clean every supported file in a folder into a new folder beside it.
- Save reports as text or JSON, with SHA-256 hashes.
- Use the same engine from scripts with `lazascrub-cli.exe`.

## Download

Download `LazaScrub-v1.0.0-windows-x64.zip`, extract it, and open `LazaScrub.exe`. It targets 64-bit Windows 10 and Windows 11. No development tools or installer are required.

`SHA256SUMS.txt` lists the hashes of the ZIP and of both programs. The ZIP also includes the programs' checksums.

## Compatibility

Cleaning removes metadata and leaves content alone. Tracked changes, hidden sheets and slides, attachments and macros are reported but kept. A photo keeps its colour profile, resolution and orientation. Cleaning a PDF invalidates digital signatures, and password-protected PDFs are reported but not cleaned.

HEIC, TIFF and RAW pictures, video, audio, OpenDocument files and the older `.doc`, `.xls` and `.ppt` formats are not supported in this version.

See `VALIDATION.md` for the checks that were run and where they stop.
